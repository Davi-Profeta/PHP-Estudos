# 🐘 PHP Estudos — SENAI

Repositório criado para reunir meus estudos, exercícios e projetos desenvolvidos durante a aprendizagem de **PHP no SENAI**, com foco na prática de programação e desenvolvimento de aplicações web.

## 📚 Conteúdos estudados

### 🧠 Lógica de Programação em PHP

* Variáveis e constantes
* Tipos de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição
* Funções
* Arrays
* Entrada e saída de dados

### 🏗️ Orientação a Objetos

* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Getters e Setters
* Construtores
* Organização e reutilização de código

### 🔄 Manipulação de Dados

* Manipulação de variáveis e arrays
* Tratamento e processamento de informações
* Estruturas para organização dos dados
* Operações com dados recebidos pela aplicação

### 🗄️ Integração com Banco de Dados

* Utilização do **Laragon** como ambiente de desenvolvimento
* Criação e gerenciamento de bancos de dados
* Conexão entre PHP e banco de dados
* Consultas SQL
* Inserção, alteração, consulta e exclusão de dados (CRUD)

### 📝 Formulários e Listagem

* Criação de formulários HTML
* Recebimento e processamento de dados com PHP
* Validação de informações
* Cadastro de dados
* Listagem de registros
* Integração entre formulários, PHP e banco de dados

### 🚀 Criação de Aplicações

Aplicação dos conhecimentos adquiridos na criação de sistemas completos, integrando **PHP, HTML, banco de dados e lógica de programação** em projetos práticos.

## 🎯 Objetivo

Este repositório serve como registro da minha evolução no aprendizado de **PHP e desenvolvimento web**, reunindo desde os primeiros exercícios de lógica até aplicações integradas com banco de dados.

> 📖 Projeto desenvolvido para fins educacionais durante o curso do **SENAI**.
